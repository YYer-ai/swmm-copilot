# M4 评估报告功能说明（superpower/TDD 流程）

> 2026-08-27 · 依 superpowers:test-driven-development 执行（RED → GREEN → 回归）

## 功能

每次评估自动生成中文评估报告（Markdown + Word 双格式），存于 `output/{片区}/{重现期}/`：

| 章节 | 内容 |
|---|---|
| 一、评估概况 | 片区/公式分区/重现期/方法/数据源 |
| 二、设计降雨 | 总雨量、芝加哥雨型参数、不透水率范围 |
| 三、模拟结果 | 溢流节点统计、最大积水深、Top5 表 |
| **四、受影响区域分析** | **OSM 地名×积水场采样 → 受影响社区排序**（阈值 ≥20mm） |
| 五、结论与建议 | 基于结果的模板化建议（核查干管/低洼社区整治） |
| 附 | 成果文件清单与规划级声明 |

**核心价值点**：第四章把 OSM 真实社区名与积水场叠加——报告直接回答「哪些社区受影响、多深」
（福田 50 年示例：梅林一村 114mm、下梅 113mm、河背村 113mm…按深度排序）。

## 模块

- `swmm_copilot/report.py`：`analyze_impact()`（地名/主干道×积水场采样）、
  `generate_markdown()`、`generate_docx()`（python-docx，中文字体已设，缺依赖时自动降级仅 MD）
- `pipeline.assess()`：评估完成即写 `report.md` / `report.docx`，结果含路径字段
- Web 界面：可视化卡片底部新增「评估报告(MD) / 报告(Word)」下载链接（artifact 白名单已扩）

## 使用

- 自动：Web 评估完成后点卡片底部「报告(Word)」；或命令行 `python examples/demo_pipeline.py` 后看
  `output/<片区>/P<重现期>/report.md`
- 依赖：Word 版需 `pip install python-docx`（未装不影响其余功能）
