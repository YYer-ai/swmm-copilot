# 可视化升级说明（地理底图 + 连续积水色差渲染）

> 2026-08-27 · 按 superpower 流程（systematic-debugging + planning-with-files）执行

## 用户需求

1. 原图只有地形和抽象管网节点，**看不出「哪是哪」**——需要道路、水系、地名等地理上下文
2. 积水表达从**离散点气泡**改为**连续色差**——在地形底图上用颜色深浅直接呈现积水深度分布

## 实现方案

### 图层栈（自下而上）

| 层 | 内容 | 来源 |
|---|---|---|
| 1 | 灰阶山体阴影（hillshade） | Copernicus GLO-30 DEM |
| 2 | **连续积水深度场**（浅蓝→深蓝色差，越深越蓝） | 节点溢流深高斯核插值（λ=0.012°，60×72 网格） |
| 3 | 水系（蓝色线） | OSM Overpass |
| 4 | 道路（主干道黄色粗线 / 一般道路白色细线） | OSM Overpass |
| 5 | 地名标注（白色文字+深色描边，自动抽稀避让） | OSM place 节点 |
| 6 | 排放口（绿三角）、积水节点（深蓝小点，悬停查深度） | 模型输出 |

### 数据流

- `osm.py`（新增）：Overpass 拉取道路/水系/地名 → GeoJSON 缓存 → 之后离线可用；拉取失败不阻塞评估（仅少底图层）
- `pipeline._flood_grid`（新增）：64 个节点积水深 → 高斯核加权插值 → 连续积水场（供前端色差渲染）
- `agent.run_assessment`：回传模型的结果**剥离 viz 大字段**（几何数据只给前端，模型只收摘要）——修复了 64KB 数据触发 LLM 400 的问题

## 过程中按 systematic-debugging 修复的根因

| 问题 | 根因 | 修复 |
|---|---|---|
| pipeline.py 语法损坏 | 编辑锚点选用 `_downsample` 函数头，被新函数吞掉 | 重写区段恢复两个函数 |
| Overpass 406 | 拒绝默认 Python UA | 加 User-Agent 标识 |
| 地名 0 个 | node 元素无 geometry 键，被 `if not geom: continue` 跳过 | place 分支前置处理 |
| LLM 400 Bad Request | 64KB viz 几何数据塞进 tool message | 模型只收摘要字段 |
